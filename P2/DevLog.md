Focus of Sprint: Implementation of a proper coin value, restrictions based on how many coins the player has, and displaying the number of coins in the player's possession.
Implemented and Complete: A UI display showing the number of coins the player has. Built-in purse tracker keeping track of how many coins the player has internally. Preventing player from investing into construction projects if the player does not possess sufficient funds. Implemented proper tracking for releasing the interact key before all the coin slots are filled.

Engineer's Journal: The biggest problems I had were continuing to adhere to the frameworks and requirements from the first project, and having to work my current knowledge of Unity around it. The hardest thing to implement was the actual UI tracking of the current purse value. I tried doing it originally with skills I learned from a class, but realized some limitations quickly that I didn't know how to work around. With some tutorial based assistance and some looking things up, I put together a new interface, and fired everything coin related essentially out from the Player itself, which was then read and updated by the UIManager whenever a coin related even happened. So if the coin value on the player changed, the UI display would change with it live. My only gripe is that I haven't found a way to work in a count-down reduction on your coin pouch when interacting with the mound, since currently it just takes all the money in one go. Beyond that, I don't think I needed to alter my scope. I'm still keeping things simple, just implementing more features at their core most level.

Creating the pickup coin and incrementing the internal coin purse itself was the easiest part. I had a much simpler solution then, since I was only worrying about an internal value on the Player. When I moved to having to update a UI display, that is when things got a little more complicated. Any of the other scripts that utilize purse changing methods, like the mound itself, talk to the interface instead of the Player directly, to keep the two remaining separate from one another.
